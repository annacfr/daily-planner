# Проверка первой версии

Дата проверки: 6 октября 2026 года.

## Подтверждено

- `node scripts/validate.mjs`: корректны четыре исходных JSON-файла, схемы и связи.
- `node --check js/app.js`, `node --check js/model.js`: JavaScript проходит проверку синтаксиса.
- 17 сценариев валидатора: пример, день без тренировки, пропуск необязательных полей, лишние поля, неверная дозировка, непарные sets/reps, одинаковые id, невозможная дата, сортировка, порядок start/end, несоответствие даты/id тренировки, превышение длительности, пустой workout, неизвестная группа мышц, неверные границы дня.
- Проверки модели: пропуск повреждённого события, default summary/config, дата в Москве, объединение пересекающихся занятых интервалов.
- 11 сценариев выполнения настоящего `app.js` в минимальной тестовой DOM-среде: отображение событий, установка/снятие галочки, необязательные поля, повреждённый/недоступный JSON дня, пустая/вчерашняя тренировка, программа и возврат, отсутствие ссылки без тренировки, отключённый storage, изоляция дат, сохранение показанного дня при неудачном обновлении.
- Все ссылки на локальные assets из HTML существуют. Все JSON-файлы парсятся.

Команды и тестовые сценарии находятся в приложенных `verify-planner.mjs` и `verify-runtime.mjs`. Запускать их из папки, содержащей `daily-planner/`, с Node.js 22+.

## Ещё не проверено

- Визуальное отображение на ширине 390 px и desktop.
- Работа в настоящем Safari/WebKit или на физическом iPhone.
- GitHub Actions на аккаунте владельца, тариф и доступность приватного Pages.
- Репозиторий и опубликованный URL: они пока не созданы.

DOM-среда проверяет поведение JavaScript, но не CSS, геометрию, зоны нажатия или браузерную совместимость. Установка тестовых браузеров в этой среде не удалась; это не успешная проверка мобильного интерфейса. Публикация и браузерная проверка остаются обязательными этапами.
